# hfd-landscape-explorer

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

## Adding Historical Map Datasets

See `DATASETS.md` for the complete pipeline for adding new PMTiles datasets from georeferenced rasters (ECW, GeoTIFF, etc.).

This project was created using `bun init` in bun v1.3.13. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
